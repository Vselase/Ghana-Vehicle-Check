How it works

Built on registries that already exist

01

Enter the plate

Any officer, insurer, buyer, or citizen types in a registration number — no login or account required for a basic check.

02

We query two registries

The DVLA roadworthy certificate database and the National Insurance Commission's motor insurance database are checked in real time.

03

One clear result

A single certificate-style result shows roadworthy status, insurance status, and expiry dates — flagged clearly if either has lapsed.

Data sources

Two registries, one answer

Ghana already collects this data — it simply isn't joined into a single public-facing lookup. This tool sits on top of existing systems rather than replacing them.

Source

DVLA Roadworthy Registry

Certificate issue and expiry data from licensed vehicle testing stations nationwide.

Source

NIC Motor Insurance Database

Active policy verification across licensed underwriters, per the NIC's existing reporting mandate.

Use case

Police & MTTD checkpoints

Instant field verification during routine stops, replacing manual document inspection.

Use case

Used-car buyers

Public due-diligence check before a private vehicle purchase, similar to gov.uk's MOT history tool.
